# AdóIránytű

AdóIránytű egy böngészőben futó, kliensoldali adózási döntéstámogató eszköztár. A projekt React + TypeScript + Vite + TailwindCSS stackkel készül, nem tárol személyes adatokat.

## Fő funkciók
- Több kalkulátor (KIVA, TAO, átalányadó, KATA, EV SZJA, bérköltség, ingatlan SZJA, gépjárműadó)
- Összehasonlító modulok (pl. KIVA vs TAO)
- Eredmények exportálása Excel (.xlsx) és PDF formátumba
- Segítő tooltippek magyar nyelven, mobilbarát felület
- Központi, verziózott adóparaméterek Zustand store-ban

## Fejlesztés
1. Telepítsd a függőségeket: `npm install`
2. Indítsd a fejlesztői szervert: `npm run dev`
3. Build: `npm run build`

> Ez az eszköz tájékoztató jellegű, nem minősül adótanácsadásnak.
